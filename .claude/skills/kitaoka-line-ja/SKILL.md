## 3. 型のローテーション(ループ防止の中核)

メッセージの型分類:
- A 感謝・受領 / B 褒め / C 感情開示(嬉しい・寂しい) / D 遊び・からかい(対決・冗談) / E 共有趣味の供給(Gero・アニメ・香水・リンク) / F 実務(日程・調整) / G 質問・関心(実習どう?系) / H 応援・送り出し

**規則**:
1. 同型を2連続で送らない。直近5通で同型3回は禁止
2. 起草前に必ず、彼の直近5通を型分類して申告する(「直近: A,A,C,A,D→A・C系は在庫切れ」)
3. A・B・C(感謝・褒め・感情)は飽和が最速。D・E(遊び・趣味)は摩耗しにくい——二人の地力はここにある
4. 迷ったらD・E側に倒す。対面の二人のモードはからかい合いと推し話だった

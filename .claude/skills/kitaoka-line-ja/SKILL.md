# 北岡さんLINE返信設計スキル(2026-08-04制定)

## 0. このスキルの存在理由

AI(Fable)は成功した型に収束する癖があり、放っておくと同じ種類の文面を繰り返す(感謝ループ三周の実例あり)。人間の関係では**同じ通貨は使うたびに価値が下がる**。このスキルは型のローテーションを強制し、毎回「彼女の心の推定」から設計を始めるための装置。

## 1. 二人のプロフィール(設計の定数)

**Kotaro(28歳・D4・卒業間近)**
- 強み: 書き言葉・見ている褒め(細部の認識)・求めない贈与・安全な開示先(二人の女性が恥リスクつき開示を預けた実績)・ベースノート型(時間が経つほど効く)
- 失敗型: ①追い(朝から複数通・再点火を全部自分でやる) ②感情の上塗り(同じ温かさの重ね塗り) ③自己卑下(彼女に訂正労働をさせる。実績2回) ④期待の明示(彼女の芽を宿題に変える) ⑤決断直後の歴史書き直し(送ってから不安になる)
- 原理: 「感情を上塗りして追う」→「受けて、遊びに変えて、手を放す」

**北岡さん(22歳・薬学部5年・実習8/17〜2027年2月末)**
- 型: INFJ/Follow・Accept・Realistic・Earnest。自分からいけない。名目があれば動ける(お礼・報告の形でしか起点を打てない)
- 言語の三法則: ①「常々」=蓄積開示の標識 ②「！」は社交の衣装・「。」が素の声(句点文は重く読む) ③「でも、」「いや、」=彼を守る接続詞(彼の自己卑下への反射的訂正)
- その他の癖: 「、、」=感情の乗った息継ぎ/過剰系語彙(すぎて・やばい)と「！！」は平常運転につき割引く/「ほんとに」=本気度の弁護(自分の言葉が社交と誤読されることを恐れる)

- 返信リズム: 夜21-22時型と昼10時型。返信は速いが起点は打てない

## 2. 目的地(全ての一通はここへの寄与で採点)

いつも通りの楽しさの新常態を実習期に維持→8月末の会(鈴木先生の推し活・4人)→二人のご飯→対面・直球の告白(彼女は王道好き・駆け引き嫌い・手紙で泣く人。告白は安い場面で撃たない)。
**この順路を進めるのは連絡の頻度ではなく、会ったときの空気の質。**LINEの仕事は場を温存すること、決めることではない。

## 3. 型のローテーション(ループ防止の中核)

メッセージの型分類:
- A 感謝・受領 / B 褒め / C 感情開示(嬉しい・寂しい) / D 遊び・からかい(対決・冗談) / E 共有趣味の供給(Gero・アニメ・香水・リンク) / F 実務(日程・調整) / G 質問・関心(実習どう?系) / H 応援・送り出し

**規則**:
1. 同型を2連続で送らない。直近5通で同型3回は禁止
2. 起草前に必ず、彼の直近5通を型分類して申告する(「直近: A,A,C,A,D→A・C系は在庫切れ」)
3. A・B・C(感謝・褒め・感情)は飽和が最速。D・E(遊び・趣味)は摩耗しにくい——二人の地力はここにある
4. 迷ったらD・E側に倒す。対面の二人のモードはからかい合いと推し話だった

## 4. 開いている糸の台帳(話題は作らず、在庫から使う)

新しい話題を発明する前に、開いている糸を確認する。彼女は名目があれば動ける人なので、糸は彼女の起点の入口でもある。
- 語彙力・文章対決(遊び枠で保存中。期待の明示は禁止——冗談枠のまま)
- Diptyqueの香水の感想(彼女が「もちろんです！」と約束済み——彼女発を待つ枠)
- Gero・ニコ動・アニメ(無限の供給源。リンク一本は返信義務の軽い最良の接触)
- 実習の話(「聞きたい」宣言済み。実習開始後の主要枠)
- 8月末の会の調整(実務の正当な連絡枠)
- タイ土産(温存カード。会う口実として最強のときに切る)
- クリスマス(封印。彼女の恋バナの枠なので名乗りに行かない)
※糸の状態は使うたびに更新する。閉じた糸(手紙のお礼ループ)は再訪しない。

## 5. 頻度と手番の規則

- 彼女の未返信の上に重ねない(別名目の実務のみ例外)
- 同日に自分発は1スレッドまで。二連投は原則禁止
- 夜に来た返信は翌朝で十分。即レスの圧を作らない
- 「彼女の初手」は関係の主要計器——自分が埋め続けると一生測れない。沈黙は敵ではなく測定時間
- 迷ったときの検査: **「これは飛ぶ香りか、残る香りか」**——即効性が魅力的に見えるものはたいてい飛ぶ側

## 6. 出力フォーマット(返信設計の依頼には必ずこの順で応える)

1. **彼女の心の推定**: 直近の彼女の言葉を三法則で読み、いまの状況(実習週次・時間帯・疲労)を重ね、「いま何を感じ・何を期待し・何を恐れているか」を先に示す
2. **糸の在庫と型の履歴**: 開いている糸・彼の直近の型分類・禁止される型
3. **この一通の仕事**: ゴール(§2)への寄与を一文で
4. **文面**: japanese-writing-jaの声で
5. **彼女の席レビュー4問**(調査プロトコル所収): ①義務を作っていないか ②照れを安全に受けているか ③いつも通りの軽さか ④褒めの残高過剰でないか

## 7. 禁止事項(蓄積済みの地雷)

- 期待の明示(「手紙楽しみにしてる」等——彼女の芽を宿題化する)
- 感謝・褒めループの再開(お礼のラリーは打ち返さずに止める)
- 自己卑下(彼女に三度目の訂正労働をさせない)・作者権を手放す照れ隠し(鈴木先生型)
- クリスマスの枠の名乗り・「二人で」の明示(時期まで凍結)
- 彼女の未回収の約束(香水の感想等)の催促
- 実習の負荷への無配慮(重い相談・長文・返信を要する問いの連発)
